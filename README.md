## Download & Install

1. Open the [**Latest Release**](https://github.com/angelolockdev/omniflow-releases/releases/latest).
2. Download the archive for your browser:
   - **Chrome / Edge / Brave / Arc:** `omniflow-extension-v*.zip`
   - **Firefox (128+):** `omniflow-firefox-v*.zip` (or `.xpi`)
3. Extract the archive to a permanent folder on your computer.
4. Load it in your browser:
   - **Chromium (`chrome://extensions`):** Enable **Developer mode** → click **Load unpacked** → select the extracted folder.
   - **Firefox (`about:debugging#/runtime/this-firefox`):** Click **Load Temporary Add-on…** → select `manifest.json` inside the extracted folder.
